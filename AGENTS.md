# P9 Skills repository instructions

- Read the [Skill Authoring Guide](docs/SKILL_AUTHORING_GUIDE.md) before creating or changing a skill. Follow its [language strategy](docs/SKILL_AUTHORING_GUIDE.md#language-strategy) and [workflow rules for model reliability](docs/SKILL_AUTHORING_GUIDE.md#workflow-and-model-reliability).
- Start new skills from the [skill template](templates/skill/SKILL.md) and keep the packaged skill usable on its own.
- Preserve existing invocation names, inputs, outputs, and supported environments where possible. Document breaking changes and provide migration steps.
- Update the [Skill Catalog](docs/SKILL_CATALOG.md) when a skill is added, removed, moved, or its catalog information changes.
- Complete the [Skill Review Checklist](docs/SKILL_REVIEW_CHECKLIST.md) and report any verification gaps before handing off the change.
- Limit edits to the requested skills and their related repository documents. Leave unrelated skills untouched.
